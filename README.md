# crossref-drones

Сбор статей о БПЛА из Crossref и тематическая статистика по их **названиям**.

Скрипт ищет в Crossref работы, в названии которых встречаются «дронные» слова
(БПЛА, БВС, беспилотник, дрон, квадрокоптер, мультикоптер, UAV, UAS, drone,
quadcopter, quadrotor, multirotor, FPV), снимает дубли по DOI и раскладывает
названия по 14 тематическим рубрикам.

Зависимостей нет — нужен только Python 3.8+.

## Использование

### 1. Выгрузка из Crossref

```bash
python3 crossref_drones.py fetch --out works.json --from-year 2015
```

Полезные ключи:

| Ключ | Назначение |
|------|------------|
| `--out` | куда сохранить JSON (по умолчанию `works.json`) |
| `--rows` | предел записей на один поисковый термин |
| `--from-year` | только публикации с этого года |
| `--issn` | ограничить одним журналом по ISSN |
| `--mailto` | e-mail для «вежливого пула» Crossref (необязательно) |

Поиск Crossref нечёткий: он цепляет статьи, где термин встречается только в
аннотации или в списке литературы. Поэтому после выгрузки остаются лишь записи,
где слово стоит **в названии**.

### 2. Статистика

```bash
python3 crossref_drones.py stats works.json --csv drones.csv --report report.txt
```

На вход принимается либо JSON от `fetch`, либо обычный текстовый файл со
списком названий — по одному в строке. Второй вариант удобен, когда названия
выгружены вручную (eLibrary, РИНЦ, веб-интерфейс Crossref):

```bash
python3 crossref_drones.py stats titles.txt --csv drones.csv
```

Отчёт включает: общее число статей, диапазон лет, языки, распределение по
рубрикам (главная рубрика и все совпадения), динамику по годам с ведущей темой
года, топ журналов и частоту ключевых слов в названиях.

## Тематические рубрики

Радиолокация и обнаружение · РЭБ и противодействие · Компьютерное зрение и ИИ ·
Навигация и позиционирование · Управление и автопилот · Маршруты и групповое
применение · Связь и антенны · Мониторинг и съёмка · Сельское хозяйство и
экология · Конструкция и аэродинамика · Энергетика · Полезная нагрузка и
доставка · Моделирование и испытания · Правовые и экономические вопросы.

Рубрика присваивается по ключевым словам названия. Название может попасть
сразу в несколько рубрик — тогда главной становится та, что выше по приоритету,
а в разделе «все совпадения» учитываются все. Правила лежат в списке
`CATEGORIES` в начале скрипта и правятся под свою задачу.
